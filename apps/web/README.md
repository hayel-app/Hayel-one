# Hayel Web Application

This directory is reserved for the Hayel web application.

The web layer must consume canonical application contracts and must not contain country-specific legal calculations, direct financial ledger manipulation, or authorization bypasses.

## UI requirements

- Follow Nova's approved Hayel brand guidelines.
- Support the agreed bilingual experience.
- Keep accessibility and responsive behavior as first-class requirements.
- Keep domain workflows separate from presentational components.
